# Financial Rules

## 1. Денежные значения

Запрещено использовать float и double для хранения денег.

Денежные значения хранятся в минимальных единицах валюты
(например, копейки для RUB) с указанием валюты.

## 2. Валюты

Каждый финансовый счет принадлежит одной валюте.

Перевод между счетами разных валют запрещен в первой версии.

FX-конвертация не входит в текущий объём проекта.

## 3. Double-entry bookkeeping

Каждая финансовая операция должна создавать сбалансированные
финансовые проводки.

Сумма дебетовых и кредитовых записей для одной операции
и одной валюты должна совпадать.

## 4. Неизменяемость Ledger

Созданные финансовые проводки нельзя изменять или удалять.

Для отмены финансового эффекта создается компенсирующая операция.

## 5. Идемпотентность

Повторная обработка одной финансовой операции не должна
создавать повторное списание или зачисление.

Для этого используются устойчивые идентификаторы операций,
idempotency keys и уникальные ограничения БД.

## 6. Конкурентный доступ

Одновременные операции с одним счетом не должны приводить
к отрицательному балансу или потере обновлений.

## 7. Атомарность

Создание проводок и изменение текущего состояния баланса
должны выполняться атомарно в рамках транзакции Ledger Service.

## 8. Восстановление

Если сервис не получил ответ на запрос, он не должен считать,
что финансовая операция точно не состоялась.

Необходимо уметь проверить состояние операции и безопасно
повторить запрос с тем же устойчивым идентификатором.
