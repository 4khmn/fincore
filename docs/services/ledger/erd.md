# Ledger Service — ERD

## 1. ACCOUNTS

Финансовые счета пользователей и системные счета.

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| id | UUID | PK | Идентификатор счёта |
| owner_user_id | UUID | NULL | Владелец счёта |
| account_type | VARCHAR(20) | NOT NULL | USER или SYSTEM |
| currency | VARCHAR(3) | NOT NULL | RUB, EUR, USD |
| status | VARCHAR(20) | NOT NULL | ACTIVE, BLOCKED, CLOSED |
| created_at | TIMESTAMPTZ | NOT NULL | Дата создания |

Примечания:
- Для USER owner_user_id обязателен.
- Для SYSTEM owner_user_id равен NULL.
- Системный счёт используется как источник виртуальных денег.
- Один пользователь может иметь максимум пять пользовательских
  счетов.
- Повторение валют разрешено.

## 2. ACCOUNT_BALANCES

Текущее состояние баланса счёта.

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| account_id | UUID | PK, FK | Ссылка на ACCOUNTS |
| balance_minor | BIGINT | NOT NULL | Баланс в минимальных единицах |
| updated_at | TIMESTAMPTZ | NOT NULL | Дата обновления |

Примечания:
- Баланс хранится в минимальных единицах валюты.
- Для RUB, EUR и USD одна единица равна 1/100 валютной единицы.
- Баланс обновляется атомарно вместе с финансовыми записями.
- Отрицательный баланс пользовательского счёта запрещён.

## 3. LEDGER_TRANSACTIONS

Одна завершённая финансовая операция.

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| id | UUID | PK | Идентификатор операции |
| operation_id | UUID | UNIQUE, NOT NULL | Идентификатор бизнес-операции |
| operation_type | VARCHAR(30) | NOT NULL | TOP_UP, TRANSFER |
| status | VARCHAR(20) | NOT NULL | Статус операции |
| created_at | TIMESTAMPTZ | NOT NULL | Дата создания |

Примечания:
- operation_id обеспечивает защиту от повторного проведения.
- Для одного operation_id может существовать только одна
  финансовая операция.
- Завершённые операции не редактируются и не удаляются.

## 4. LEDGER_ENTRIES

Отдельные записи движения денег.

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| id | UUID | PK | Идентификатор записи |
| transaction_id | UUID | FK, NOT NULL | Финансовая операция |
| account_id | UUID | FK, NOT NULL | Счёт |
| amount_minor | BIGINT | NOT NULL | Сумма со знаком |
| currency | VARCHAR(3) | NOT NULL | Валюта |
| created_at | TIMESTAMPTZ | NOT NULL | Дата создания |

Примечания:
- Положительная сумма означает поступление.
- Отрицательная сумма означает списание.
- Записи одной операции в одной валюте должны суммироваться
  в ноль.
- Записи нельзя изменять или удалять.
- Для обычного перевода создаются минимум две записи.

## Связи

- ACCOUNTS 1:N LEDGER_ENTRIES.
- LEDGER_TRANSACTIONS 1:N LEDGER_ENTRIES.
- ACCOUNTS 1:1 ACCOUNT_BALANCES.

## Важные ограничения

- Нельзя проводить операцию между счетами разных валют.
- Нельзя списывать больше доступного баланса.
- Проводки и обновление балансов выполняются в одной транзакции БД.
- Повторная обработка operation_id не создаёт новых проводок.
- Изменение уже проведённой операции выполняется через новую
  компенсирующую операцию, а не редактирование старой.

## Примечание о системных счетах

Виртуальное пополнение на 1000 RUB создаёт две записи:

1. Системный счёт: -100000.
2. Пользовательский счёт: +100000.

Таким образом, деньги не возникают в журнале только на одном счёте.
