# Ledger Service — API

## Назначение

Ledger Service отвечает за финансовые счета, балансы и движение
денежных средств.

Это единственный сервис, который изменяет финансовое состояние
счетов и создаёт финансовые записи.

Base path: /api/v1

## 1. Создание счёта

POST /accounts

Авторизация: обязательна.

Request:

{
"currency": "RUB"
}

Response: 201 Created

{
"id": "account-uuid",
"currency": "RUB",
"balance": "0.00",
"status": "ACTIVE",
"createdAt": "2026-11-18T10:00:00Z"
}

Ошибки:
- 400 — неподдерживаемая валюта.
- 401 — пользователь не авторизован.
- 409 — достигнут лимит в пять счетов.

Правила:
- Счёт принадлежит пользователю из JWT.
- Поддерживаемые валюты: RUB, EUR, USD.
- Один пользователь может иметь максимум пять счетов.
- Повторение валют разрешено.
- Новый счёт всегда имеет нулевой баланс.

## 2. Получение списка счетов

GET /accounts

Авторизация: обязательна.

Response: 200 OK

[
{
"id": "account-uuid-1",
"currency": "RUB",
"balance": "1500.50",
"status": "ACTIVE"
},
{
"id": "account-uuid-2",
"currency": "EUR",
"balance": "100.00",
"status": "ACTIVE"
}
]

Возвращаются только счета текущего пользователя.

## 3. Получение информации о счёте

GET /accounts/{accountId}

Авторизация: обязательна.

Response: 200 OK

{
"id": "account-uuid",
"currency": "RUB",
"balance": "1500.50",
"status": "ACTIVE",
"createdAt": "2026-11-18T10:00:00Z"
}

Ошибки:
- 401 — пользователь не авторизован.
- 404 — счёт не найден или не принадлежит пользователю.

## 4. Получение баланса

GET /accounts/{accountId}/balance

Авторизация: обязательна.

Response: 200 OK

{
"accountId": "account-uuid",
"balance": "1500.50",
"currency": "RUB"
}

Ошибки:
- 401 — пользователь не авторизован.
- 404 — счёт не найден или не принадлежит пользователю.

## 5. Виртуальное пополнение

POST /accounts/{accountId}/top-ups

Авторизация: обязательна.

Request:

{
"amount": "1500.50",
"idempotencyKey": "topup-unique-key"
}

Response: 201 Created

{
"transactionId": "transaction-uuid",
"accountId": "account-uuid",
"amount": "1500.50",
"currency": "RUB",
"status": "COMPLETED"
}

Ошибки:
- 400 — некорректная сумма.
- 401 — пользователь не авторизован.
- 404 — счёт не найден или не принадлежит пользователю.
- 409 — конфликт idempotency key.

Правила:
- Сумма должна быть больше нуля.
- Валюта определяется валютой счёта.
- Пополнение является симуляцией.
- Деньги поступают со специального системного счёта.
- Повтор запроса с тем же ключом не создаёт новое пополнение.

## Внутренние операции

Следующие операции не являются публичными REST-ручками.

Они доступны только внутренним компонентам через gRPC.

### CreateTransfer

Запрос на проведение перевода между двумя счетами.

Входные данные:
- operationId — уникальный идентификатор операции.
- fromAccountId — счёт отправителя.
- toAccountId — счёт получателя.
- amountMinor — сумма в минимальных единицах.
- currency — валюта.

Результат:
- transactionId;
- operationId;
- status.

Правила:
- Оба счёта должны существовать и быть активными.
- Оба счёта должны иметь одну валюту.
- Отправитель должен иметь достаточный баланс.
- Операция должна быть атомарной.
- Повторный вызов с тем же operationId не должен повторно
  изменять балансы.

### GetOperationStatus

Позволяет получить результат ранее отправленной финансовой
операции по operationId.

Нужен для обработки ситуаций, когда gRPC-запрос завершился
таймаутом и Transfer Service не знает, успел ли Ledger провести
операцию.
