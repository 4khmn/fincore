# Identity Service — ERD

## USERS

Основная таблица пользователей.

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| id | UUID | PK | Идентификатор пользователя |
| email | VARCHAR(255) | NOT NULL, UNIQUE | Email |
| password_hash | VARCHAR(255) | NOT NULL | Хеш пароля |
| role | VARCHAR(30) | NOT NULL | Роль пользователя |
| created_at | TIMESTAMP WITH TIME ZONE | NOT NULL | Дата регистрации |
| updated_at | TIMESTAMP WITH TIME ZONE | NOT NULL | Дата изменения |

## Правила

- email уникален.
- Пароль хранится только в виде хеша.
- Роль по умолчанию — USER.
- Удаление пользователя не должно автоматически удалять
  его финансовую историю в других сервисах.

## Связи с другими сервисами

Identity Service не имеет SQL-связей с таблицами других сервисов.

Идентификатор пользователя (USERS.id) используется другими
сервисами как внешний идентификатор владельца данных.
