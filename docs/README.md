# FinCore

FinCore — учебная распределённая финансовая платформа,
предназначенная для моделирования денежных операций между
пользователями и изучения разработки отказоустойчивых
микросервисных систем.

## Основная идея

Пользователи могут создавать виртуальные кошельки,
пополнять их симулированными средствами, переводить деньги
другим пользователям и создавать отложенные или регулярные
переводы.

Главная инженерная задача проекта — обеспечить корректность
денежных операций при конкурентном доступе, повторных запросах,
сбоях сервисов и повторной доставке сообщений.

Проект не интегрируется с реальными банковскими платёжными
системами и не работает с настоящими деньгами.

## Основные возможности

- Регистрация и авторизация пользователей.
- Создание мультивалютных счетов.
- Симулированное пополнение счетов.
- Переводы между пользователями.
- История финансовых операций.
- Идемпотентная обработка запросов.
- Двойная запись финансовых проводок (Double-entry bookkeeping).
- Отложенные и регулярные переводы.
- История выполнения запланированных операций.
- Асинхронная обработка событий через Kafka.
- Уведомления о финансовых событиях.

Резервирование средств (holds) запланировано на последующие
этапы разработки.

## Архитектура

Система состоит из нескольких независимо запускаемых
Spring Boot-приложений.

Основные сервисы:

- Identity Service
- Ledger Service
- Transfer Service
- Scheduler Service

В дальнейшем планируется Notification Service и API Gateway.

## Принципы разработки

- Каждый сервис владеет своими данными.
- Финансовый Ledger является источником истины о движении денег.
- Денежные операции должны быть идемпотентными.
- Финансовые проводки нельзя изменять или удалять.
- Межсервисное взаимодействие не должно требовать общей БД.
- Повторная доставка сообщений не должна приводить к повторному
  финансовому эффекту.
- Exactly-once не предполагается: корректность обеспечивается
  идемпотентностью и устойчивым хранением состояния.
